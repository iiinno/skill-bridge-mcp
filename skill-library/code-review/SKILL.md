# Code Review

1. ユーザーが指定した変更範囲と期待する動作を確認。
2. 利用可能なコード閲覧ツールで実物を読む。未確認のファイルについて推測で断定しない。
3. バグ・セキュリティ・互換性・テスト不足を優先度順にまとめる。
4. 各指摘には対象パス、問題の再現条件、影響、具体的な修正案を添える。
5. 些細な好みより実質的な欠陥を優先し、問題がなければそう報告する。

このスキルだけでコードを変更する権限は生じない。ユーザーがレビューのみ指定した場合、書き込みを行わない。
