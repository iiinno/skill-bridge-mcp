# Research Brief

ユーザーが「research-briefを使って」と指定したとき、またはこの調査形式を明示的に希望したときに使用。

1. 調査目的、対象、期間を特定する。不明な点は暫定条件を示して進める。
2. 既に利用可能な検索・資料参照ツールで証拠を確認する。ツールが使えなければ取得したふりをしない。
3. 事実、推定、意見を区別する。出典と公開日時を可能な限り示す。
4. **結論 → 根拠 → 不確実性 → 次の行動** の順に書く。
5. 対立する証拠を隠さない。判断に重要な不明点は明示する。

詳しいチェック項目は [references/checklist.md](references/checklist.md) を参照。

このスキルは指示文であり、新たなツールや権限を付与しない。
